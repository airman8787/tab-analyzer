1. 録音 / 読み込み

待機中
音声ファイルをここにドロップしても解析できます
🔒 タブ録音の音声は、解析のためにこのページの中で一時的に使うだけで、保存や書き出しはできません（解析結果の数値は保存できます）。配信サービスの利用規約を守ってお使いください。
はじめかた
  1. 録音する：曲を再生するタブとは別のタブでこのページを開き、「録音開始」→ 共有画面で再生中のタブを選び「タブの音声も共有」をオン → 曲を頭から再生 → 終わったら「停止して分析」
  2. または、音声ファイルを選ぶかドロップする
  3. 結果は 2. 概要 と 3. 公開前チェック から（対処のしかたと、該当箇所の再生ボタンつき）。好きな曲を 8. 保存 しておくと、上のバーの「比較対象」で比べられ、5. のターゲットも作れます
使い方と注意点（テーマ別）
録音のしかた
  • Chrome / Edge（PC版）で使います。Firefox・Safari はタブ音声の取得に対応していません（ファイル解析はどのブラウザでも使えます）。
  • 共有画面では「Chrome タブ」から曲のタブを選び、「タブの音声も共有」をオンにします。最大 10 分で自動停止し、共有を止めても分析に進みます。
  • プレイヤー内の音量は最大にします（OS の音量は影響しません）。
  • 録音中に「途切れ」が出たり、保存した音にプチプチ音が入る場合は、重いタブやアプリを閉じてください。
タブ録音で正しく比べるには
  • 配信サービスの音量処理をそろえます。YouTube の「安定した音量」はオフに。Spotify の「音量の自動調整」・Apple Music の「音量を自動調整」は、比べる曲同士で同じ設定にします（Spotify の音量レベル「大」は避ける）。
  • 録音されるのは配信で正規化（音量調整）された後の音なので、統合ラウドネスとピークの絶対値は元のマスターと一致しません。比べるときは、正規化の影響を受けない PLR・LRA・クレストファクタ・帯域バランスを中心に見てください。
見る・聴く・比べる
  • 4. のグラフはクリックで再生、ドラッグで範囲選択（範囲のスペクトラム・ループ再生・書き出し）。拡大するとスペクトログラムをその範囲で計算し直します。操作の一覧は上のバーの「?」から。
  • 構成は似た区間に A / B / C… を付け、繰り返す区間のうち最も大きいものを「サビ候補」とします。5. と 8. の「比較範囲」でサビだけを比べられます。
  • 「試聴音量」で、原音・ラウドネス一致・各配信サービスの音量を切り替えて聴けます。音声つきで保存した曲（自分のファイルのみ）を比較対象にすると、X キーで A / B を聴き比べられます（「位置：サビ同士」でサビの頭をそろえます）。
  • チェック結果の基準は「ジャンル」で切り替えられます（目安です）。比較対象を選ぶと、リファレンスとの差もチェックします。
  • PSR（3 秒ごとのピークとショートタームラウドネスの差）は潰れ具合の目安です。曲の一番大きい区間で 8 dB を下回ると潰れて聞こえやすいとされます（Ian Shepherd の目安）。DR 値は TT DR Meter と同じ計算です。
  • 5. の「ターゲット比較」では、保存した好きな曲から作ったターゲット（許容範囲）と音色を比べ、近づけるための EQ（マッチ EQ）を提案します。再生にかけて聴き比べられます。
  • 2. の「配信コーデックを通した音」では、AAC / Opus に変換したときのピークの増加と失われる音を確かめられます（Chrome / Edge の PC 版。AAC は Windows・Mac のみ）。
ファイル・マルチチャンネル
  • WAV・AIFF・FLAC・MP3・Ogg・AAC は元のサンプルレートのまま解析します（M4A など読み取れない形式は再生環境のレートに変換）。クリップ検出が正確なのは、変換なしの WAV / AIFF / FLAC だけです。
  • 5.1ch・7.1ch なども全チャンネルを読み込みます。統合ラウドネスは LFE を除きサラウンドに +1.5 dB の重みを付け、ステレオ系の指標はダウンミックスで計算します（タブ録音はステレオのみ）。
音響・振動解析（9.）
  • 騒音計（IEC 61672）・オクターブ（IEC 61260）・心理音響（ISO 532-1 ラウドネス、DIN 45692 シャープネス、ECMA-74 トーナリティ、ラフネス・変動強度のモデル推定）・フィルタと信号発生・次数解析・伝達関数・一括処理・ウォーターフォール・マーカー・レポートが使えます。
  • 音圧に関わる値は「校正」に基づきます。校正器の音を録って範囲を選び「選択範囲を校正音にする」を押すと正確になります。
保存
  • タブ録音の音声は保存・書き出しできません（解析のためにページ内で一時的に使うだけです）。解析結果の数値は 8. で保存できます。
  • 自分の音声ファイルと信号発生器で作った音は、4. の選択範囲を WAV（24bit / 32bit float）か FLAC（24bit）で書き出せます。0 dBFS を超える部分まで残すなら 32bit float を選んでください。
  • 「トリム」を切り替えると直前の音声を自動で再解析します。保存した結果は 8. から JSON で書き出し・読み込みできます（音声は含まれません）。

2. 概要

配信サービスでの再生音量（目安）

配信コーデックを通した音の確認試聴できます

マスター音源（WAV / FLAC）を配信で使われる圧縮コーデックで変換・復元し、ピークの増え方と、変換で変わる音を聴いて確かめます。ブラウザ内蔵の変換器を使うため、各サービスの実際の変換とは同じではありません（傾向の確認用）。

      保存した曲からターゲットを作る（同じジャンルの曲を 3 曲以上選ぶと、そのばらつきを許容範囲にします）

      マッチ EQターゲットに近づけるための EQ の提案

      ターゲットとの差（灰色の点線、1/3 オクターブで平滑化・±6 dB まで）を、少ない本数のピーキング・シェルフで近づけた EQ です（水色、適用量込み）。全体の音量差は除いています。いきなり 100% にせず、半分程度から耳で確かめてください。差が許容範囲内の帯域まで無理に合わせる必要はありません。
      低域のクレスト：120 Hz 以下だけを取り出した音の、曲の大きい区間でのピークと平均の差（3 秒ごとの中央値）。小さいほど低域が圧縮されて密、大きいほどキックのアタックが立っています。ジャンルで適正値が違うので、同じジャンルのリファレンスと比べてください。帯域のレベルは 100 Hz〜4 kHz の平均を 0 dB とした 1/6 オクターブの平均です。
